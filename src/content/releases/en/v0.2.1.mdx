With version [0.2.0](/releases/v0.2.0), sensor activation was introduced as a central feature. Version 0.2.1 builds on this and fixes several bugs that appeared during ongoing operation, mostly around sensors.

## Fixed Bugs

### Sensors

In the sensor overview, the “Last Data Update” column always showed “No data” regardless of the available measurements. It now shows the actual time of the last measurement again. In addition, the connection status was not reliable, since sensors were sometimes shown as offline even though current measurements were coming in. The status is now determined based on the recency of the last measurement and reflects the actual connection state.

In the setup dialog, the “Activate Sensor” button was placed in its intended position. Since this version, it consistently carries this label instead of the previous “Add Sensor”, which described the process less accurately.

### Lists and map

In the list views, two features were temporarily unavailable. Pagination in the tree list, as well as the filter on the map and in the tree and group lists, are working again.

### Login

After a session expired, automatic renewal failed because the backend rejected the request. The login process was reworked so that expired sessions are again extended automatically and without manual re-login.

Feedback and bug reports are always welcome via [GitHub](https://github.com/green-ecolution/green-ecolution/issues).
